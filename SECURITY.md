# Security Policy

## Reporting a vulnerability

Please **do not** report security issues in public issues, pull requests or Discord.

Report them privately through GitHub:

1. Open the [**Security** tab](https://github.com/sichmesh/web-flasher/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, how to reproduce it and its possible impact.

Only the maintainers can see the report. We will confirm that we received it, keep you updated while we work on a fix, and credit you when the fix is published — unless you prefer to stay anonymous.

## Scope

This policy covers the SICH Web Flasher (flasher.sichmesh.org) and the firmware files it serves.

Security issues in the SICH firmware or its radio protocol: report them in [sich-firmware](https://github.com/sichmesh/sich-firmware/security). If you are unsure where an issue belongs, report it here and we will route it.

## Supported versions

Only the latest version on the `main` branch is supported.
